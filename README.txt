# Axel Nikea LLP — Website

A static, responsive corporate website for Axel Nikea LLP.

## Files

- `index.html` — website
- `styles.css` — styling
- `script.js` — navigation and enquiry email behavior
- `assets/axel-nikea-logo.png` — supplied Axel Nikea logo

## Important

The contact form is intentionally backend-free. It opens the visitor's email application and prepares an email to:

sanney@axelnikea.com

If that address is not the final public contact address, change it in:
- `index.html`
- `script.js`

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload all files and folders, keeping the same structure.
3. Open `Settings` → `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Choose `main` and `/ (root)`, then Save.
6. GitHub will provide the temporary Pages URL.

## Custom domain

In GitHub Pages settings, add:

axelnikea.com

Then configure DNS at GoDaddy as described in GitHub's current documentation.

Do not delete your GoDaddy domain. Only change its DNS records when ready.

## Before final launch

Replace placeholder project cards with verified project information and photographs. Review all company/legal claims, contact details, privacy policy and terms before public launch.
