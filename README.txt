PUBLISH TO GITHUB PAGES
1. Download and extract this ZIP.
2. Open repository: https://github.com/sanneysharma/axel-nikea-web
3. In Code, upload the contents of this folder (not the enclosing folder) to the repository root.
4. Commit the changes to the main branch.
5. Keep Settings > Pages set to Deploy from a branch, main, /(root).
6. Wait for the Pages workflow to complete, then test https://axelnikea.com.
